# CI / Jenkins guide

This project includes a Jenkins pipeline and a CI Docker compose to run builds and end-to-end Selenium tests in an automated way.

## What is already in the repository
- `Jenkinsfile` - declarative pipeline with stages: Checkout → Build → Start Services (Docker) → Unit Tests → Integration Tests → Selenium stages → Allure report.
- `docker-compose.ci.yml` - services for Postgres, app, a `maven` helper service, Selenium Hub + Chrome nodes.
- `pom.xml` - Surefire/Failsafe configured; `selenium` profile added that defines sensible defaults for remote Selenium and app base URL; Allure plugin added.

## Run CI locally (recommended flow)
1. Ensure Docker Desktop is running.
2. Start the CI compose environment:

```bash
cd /path/to/career-management
docker compose -f docker-compose.ci.yml up -d --build
```

3. Run unit tests inside the `maven` service (so the tests can access the compose network services):

```bash
# If you get JaCoCo / JVM instrumenting errors locally, skip JaCoCo:
docker compose -f docker-compose.ci.yml run --rm -e DB_HOST=postgres maven mvn -B -DskipITs=true -Djacoco.skip=true test
```

4. Run integration or Selenium tests (example: LogoutTest):

```bash
docker compose -f docker-compose.ci.yml run --rm -e DB_HOST=postgres maven mvn -Dtest=LogoutTest -Pselenium \
  -Dselenium.remote.url=http://selenium-hub:4444/wd/hub -Dapp.baseUrl=http://app:8080 -Dselenium.headless=true test
```

Tip: Selenium tests are tagged with `@Tag("selenium")`. To exclude them during a local `mvn test` run, pass `-DexcludedTags=selenium` (or set this property in your IDE run configuration).
5. Tear down after tests:

```bash
docker compose -f docker-compose.ci.yml down --volumes --remove-orphans
```

## Jenkins notes
- The `Jenkinsfile` uses `docker compose -f docker-compose.ci.yml` to start services and runs Maven commands inside the `maven` container so tests can reach `app`/`postgres`/`selenium` via compose network.
- JUnit XML reports are published by `junit` steps; Allure report is generated by `mvn allure:report` and archived.
- There are separate Selenium stages (Login, Logout, Create Ad, Search, etc.). You can add additional scenarios (up to the project max) by adding new stages that run specific test classes.

## Troubleshooting
- If a Maven dependency download times out inside CI: check network access from CI agent, or configure a Maven mirror (`settings.xml`) for your Jenkins agents.
- If tests fail locally due to missing Chrome binary: use the Docker compose flow above (remote Selenium + Chrome nodes), or install Chrome on your machine.
- If integration tests complain about DB connection on local `mvn test`: either start `docker compose -f docker-compose.ci.yml up -d postgres app` or run tests with Testcontainers.
